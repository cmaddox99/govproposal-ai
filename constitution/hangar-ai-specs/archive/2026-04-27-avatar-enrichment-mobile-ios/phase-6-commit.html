Session Summary — What the Team Learned

0
Pre-flight: Taxonomy gates decide if a label is a product avatar. "Mobile" fails all 5 gates — map sub-products (passenger-booking, check-in) instead. Always scope before scanning.
1
Identify: Check index.yaml for duplicates first. IDs must match exactly — folder name = index.yaml id = manifest id. Three places that must agree.
2
Scan: Run every structural check before touching a file. Token budgets, law domain boundaries, journeys, use cases — find all gaps at once, classify BLOCKING vs ADVISORY, then go fix.
3
Discover: Read the law registry before citing any law. ENG-9.4 looked plausible — it doesn't exist. Read before you propose.
4
Enrich: Two tracks always run together — correct first, then enrich. Enrichment grounded in real codebase evidence (reports/ios/) not invented content.
5
RAG Validate: Simulates agent retrieval. Catches over-budget files and phantom law citations that survive Phase 4. When you remove a law from a manifest, grep the full avatar directory for it.
6
Commit: ENG-13.1 Render Gate first — all evidence HTML visible in browser. Then stamp index.yaml. Then commit. Order is non-negotiable.
