The Challenge

Documentation doesn't build muscle memory.

The Hangar AI Constitution is comprehensive. Engineers know it exists. But knowing about constitutional AI development is not the same as being able to do it — on a real codebase, under real constraints, with an AI agent that enforces every law.

📉

Without constitutional practice

AI-generated code is inconsistent. Quality varies by prompt. No audit trail. No law citations. Coverage gaps discovered in production.

🏛️

With constitutional practice

Every AI agent output traces to a law. Gates enforce coverage and security. Evidence is committed. The process is repeatable by any team member.

⏳

The scaling problem

Instructor-led cohorts reach 20–30 engineers at a time. We have hundreds of teams. We need a model that scales without instructor bottlenecks.

🎯

The answer

Self-service workshops on Learning Hub. AI agent as instructor. Constitution as the enforcer. Durable artifacts as proof of completion.

How It Works

Self-service by design.
Constitution-enforced by default.

🤖

AI agent as instructor

The learner gives one bootstrap prompt. The AI agent reads the workshop guide and drives the entire experience — presenting, pausing, enforcing gates, and refusing to let the learner skip steps. No instructor required, no scheduled cohort.

🔒

Constitutional lint as the gate

aa-constitution-lint runs at every phase exit. The agent enforces exit criteria — not self-reporting, not trust. The gate either passes or it does not.

📁

Durable artifacts as proof of completion

Every workshop produces committed governance artifacts — adoption-verified.md, ADRs, proposals, evidence reports, gate passes. Learners have evidence, not just memory. Learning Hub can verify completion by artifact existence.

🏠

Application guide for your own codebase

Every workshop closes with a take-home Application Guide — a structured playbook for applying the same workflow to the learner's own system. The workshop is not the destination; the learner's production codebase is.
