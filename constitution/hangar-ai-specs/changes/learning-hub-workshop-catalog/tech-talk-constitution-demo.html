Phase 3

Characterize — Lock Behavior First

ENG-4.3 (Test-First Brownfield Law) — Write tests that describe what the code DOES, not what it SHOULD do.
ENG-4.3 — TEST-FIRST BROWNFIELD LAW ⛔

"Write characterization tests before modifying any legacy code. The tests lock current behavior — they describe what the code does, not what it should do."

✅ Why this law exists

  • Legacy code has undocumented behavior that matters
  • Without tests, refactoring silently breaks production
  • Tests become the safety net for everything that follows
  • Coverage becomes a constitutional proof

// BEFORE — ENG-6.7 ⛔ VIOLATED String query = "SELECT * FROM miles WHERE id=" + userId; Statement stmt = conn.createStatement(); ResultSet rs = stmt.executeQuery(query);
// AFTER — ENG-6.7 ⛔ SATISFIED · commit: fix(security): ENG-6.7 PreparedStatement stmt = conn.prepareStatement( "SELECT * FROM miles WHERE id = ?" ); stmt.setLong(1, userId); ResultSet rs = stmt.executeQuery();
