# AAdvantage Member Personas

## Casual Member (est. 60% of base)
**Travel:** 1-2 flights/year, earns primarily via credit card spend  
**Goal:** Earn enough for one family redemption  
**Pain:** Points expire before opportunity; doesn't know expiration date  
**Decision trigger:** Email showing points value + expiry = highest re-engagement signal

## Frequent Traveler (est. 25% of base)
**Travel:** 6-12 flights/year, earns via flights + hotel/car partners  
**Goal:** Maximize earning velocity + redeem for upgrades  
**Pain:** Can't see points value at search time; only post-selection  
**Decision trigger:** Real-time points display at search (requires `booking-bff` 7.4/10 support)

## Elite Member — Gold/Platinum/EXP (est. 10% of base, ~40% of revenue)
**Travel:** 25K–100K+ miles/year  
**Goal:** Maintain or upgrade status tier  
**Pain:** Status threshold anxiety; one missed segment can cost a tier  
**Decision trigger:** Live tier progress in the AA app (requires `loyalty-bff` — currently 5.3/10 Yellow)

## Program Manager (Internal)
**Role:** Manages partner relationships, points ledger rules, compliance  
**Goal:** Maximize program margin without degrading member satisfaction  
**Constraint:** ENG-6.4 (EU member GDPR) + BUS-4.3 (7-year transaction retention) + financial audit compliance
