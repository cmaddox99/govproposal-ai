# PRD-6.2 Retention Law — Airport Operations

## Law Summary

Employee retention is a product outcome. Internal tools that cause frustration drive turnover. Measure tool satisfaction before investing in recruiting campaigns.

---

## ✅ COMPLIANT Example

### Context

DFW ground operations is running a Q3 recruiting campaign targeting experienced gate agents ($450K budget). The assumption: more agents will reduce per-agent workload and IROP stress.

**Product Manager challenge:** Before attributing attrition to headcount shortage, validate whether tool frustration is a primary driver of departure.

### Evidence

**Exit interview analysis (n=42 gate agent departures, last 12 months):**

| Exit Reason Cited | % of Departures |
|------------------|-----------------|
| Tool frustration / outdated systems | 38% |
| Pay and benefits | 27% |
| Schedule / shift patterns | 21% |
| Management issues | 14% |

**Agent satisfaction survey (current staff, n=134, Q2 2026):**

| Tool | Satisfaction Score (1–10) | Benchmark |
|------|--------------------------|-----------|
| Gate Management System (GMS) | 4.2 | 7.0 (industry) |
| IROP notification workflow | 3.1 | 6.5 (industry) |
| Baggage status tools | 5.1 | 6.8 (industry) |

**Retention model finding:** Agents with tool satisfaction ≥ 7.0 have 18-month retention rate of 74%. Agents with satisfaction < 5.0 have 18-month retention rate of 41%.

### Validated Intervention

Reduce agent-reported tool frustration by 40% (from 4.2 to ≥ 5.9 on GMS, from 3.1 to ≥ 4.3 on IROP notifications) **before** launching Q3 recruiting campaign.

**Rationale:** Hiring into a high-frustration tool environment will not solve the retention problem. New agents will reach the same frustration threshold and depart within 18 months at the same rate.

### Metric

Internal tool satisfaction NPS (quarterly survey, current agent staff). Gate before recruiting spend: tool NPS ≥ 40 (from current −12).

### Roadmap Gate

Q3 recruiting campaign budget is released only after Q2 tool satisfaction survey shows ≥ 40% improvement on GMS and IROP notification scores.

---

## ❌ VIOLATION Example

> "We have 15% gate agent attrition. Approve the Q3 recruiting budget to backfill departures."

**Why this violates PRD-6.2:**
- Attrition treated as a headcount problem, not a product/experience problem.
- No investigation into why agents are departing.
- Hiring into a broken tool environment perpetuates the attrition cycle.
- Tool frustration (38% of exits) is addressable at lower cost than a $450K recruiting campaign.
